# Primer PR Práctica

Repositorio de práctica para aprender el flujo de Pull Requests en GitHub.

## Qué es esto

Un repo pequeño y sin riesgo donde probar cómo se crea una rama, se hace un cambio,
y se abre un Pull Request para fusionarlo a `main`.

## Cómo hacer tu primer Pull Request aquí

1. Crea una rama nueva a partir de `main`: `git checkout -b mi-cambio`
2. Haz un cambio pequeño y guárdalo: `git commit -am "Descripción del cambio"`
3. Sube la rama: `git push -u origin mi-cambio`
4. Abre el Pull Request: `gh pr create`
